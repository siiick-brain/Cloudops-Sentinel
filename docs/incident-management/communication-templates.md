# Incident communication templates

## Initial update

**Status:** Investigating  
**Impact:** State affected service and user impact.  
**Start time:** Record UTC time.  
**Next update:** State the next update time.

## Progress update

**Status:** Investigating, mitigating or monitoring  
**Impact:** State known impact.  
**Action:** State the current mitigation.  
**Next update:** State the next update time.

## Resolution update

**Status:** Resolved  
**Impact:** State the final impact window.  
**Recovery:** State the confirmed recovery signal.  
**Follow-up:** Link the incident review.
