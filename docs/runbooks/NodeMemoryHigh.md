# NodeMemoryHigh

## Symptoms and impact

Node memory use is above 90 percent. The host may reclaim memory or restart containers.

## Dashboards and queries

Review node memory and cAdvisor container working-set panels.

## Diagnosis

Identify containers with rising working sets and check for pressure or restarts.

## Mitigation

Stop the memory stress process or reduce the responsible workload. Confirm memory recovers.

## Escalation

Escalate if memory pressure continues or services restart.
